# Demo Workflow — Draft

1. Open the web application.
2. Select/draw a field in the agreed demo area.
3. Select crop, date range and language.
4. Submit analysis request.
5. Show job status.
6. Display actual satellite observation dates and imagery quality.
7. Display only indicators that were genuinely calculated.
8. Display weather context if successfully retrieved.
9. Display evidence-grounded report and limitations.
10. Explain prototype limitations.

Use verified field/date data. Label mock data clearly. Prepare a fallback recording/sample if live data or network access fails.
